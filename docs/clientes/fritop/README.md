## Uso del logo

- Para impresión o para cambiar el tamaño, usa el **SVG**: no pierde calidad.
- Para web, WhatsApp y redes sociales, usa los **PNG**.
- Las letras del logo son blancas, así que va sobre fondos oscuros o de color (naranja, negro). Sobre fondos blancos o beige se pierde.
